Auto Process Notes

Prototype · not connected to Pega

Today, getting a case's notes means typing something like “What are the notes for TSLA?” into the assistant every time — so more often than not, nobody does. Here, opening the case asks that question for you and shows the answer immediately.

1

Case is opened. Its document type (Summary or News) and client ID (ticker) come from case metadata — already on every case today.

2

The assistant matches that pair to the correct notes source, instead of an analyst searching for it by hand.

3

Notes render in the case view immediately, with the source cited — the same link an analyst would have opened themselves.
